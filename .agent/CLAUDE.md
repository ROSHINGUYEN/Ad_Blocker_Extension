# Chỉ dẫn bắt buộc

Trước khi làm bất kỳ việc gì trong repository này, bạn PHẢI đọc và tuân thủ:

1. `AGENTS.md` — quy tắc gốc (bắt buộc với mọi agent và sub-agent).
2. `SUBAGENTS.md` — bắt buộc nếu bạn tạo hoặc là sub-agent.
3. `.agent/skills/ai-coding-discipline/SKILL.md` và `.agent/skills/subagent-orchestration/SKILL.md`.

Không đọc được các file trên → dừng và báo người dùng. Không làm "theo trí nhớ".
Nếu bạn là sub-agent: brief thiếu khối CORE RULES → trả `BLOCKED`.
